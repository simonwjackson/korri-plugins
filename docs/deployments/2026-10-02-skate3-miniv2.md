continued. This plugin update does not fix that renderer problem. Gameplay,
physical controller routing through a library launch, audio, and reboot recovery
remain untested with this installed package.

The runner still requires the measured bare ISO in a library folder. Existing
extracted game data is not a discoverable ISO. Installation did not change game
files, settings, library folders, or records.

Two pre-existing failed-unit markers remain: `korri-plugin-host.service` and
`korri-sunshine-input-setup.service`. This installation does not repair those
failures or establish reboot acceptance.
